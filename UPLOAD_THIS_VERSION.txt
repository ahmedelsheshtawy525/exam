FMVA Exam Platform - Certificate FK Repair

IMPORTANT: Apply the new D1 migration to the REMOTE database before/with deployment:

npx wrangler d1 migrations apply ahmed-finance-exam-db --remote

Then deploy:

npx wrangler deploy

This version repairs legacy certificate schemas that referenced the non-existent
`attempts` table and prevents certificate issuance errors from turning a successful
exam submission into HTTP 500.

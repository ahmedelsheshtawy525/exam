UPLOAD THIS VERSION — v10.0

Certificate flow:
- Migration 0008 enables native credentials for existing exams.
- Already-passed / already-submitted attempts can receive a certificate when the exam is certificate-enabled.
- The student result page shows a prominent "Your certificate is ready" section.
- Admin > Certificates remains available for View / Revoke / Restore.
- Public verification remains at /verify/CERT-...
- App cache is bumped to v10.0.

Deployment:
1. Deploy this project.
2. Apply migration 0008 to the SAME D1 database:
   npx wrangler d1 migrations apply DB --remote
3. Hard refresh with Ctrl+Shift+R.
4. Open the FMVA result again. If it is passed, the certificate will be issued automatically.
5. Then click Open Certificate.

Do NOT rerun migration 0007 if it is already applied.
